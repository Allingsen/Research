# Sentiment Analysis Project

## Files
### bluesky_scraper
A python script using the Bluesky API that pulls all posts that contain keywords relating to our research. Should be ran frequently to update our results
### classification_tests
A python script comparing multiple different classificaiton techniques. Can be added to if more techniques are being explored
### dataset_1_cleaner
A python script to remove the tagged_subsets as described in dataset_descriptions.md to create Dataset A. Should not be modified, Dataset A should be static
### final_research_ncur
A python script that was used to create poster elements for the NCUR poster. Provides an overview of the projects overall process, however should be flushed out more in this next phase.
